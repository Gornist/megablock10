Ты ведёшь Godot-часть Мегаблока №10 (`netrun/`) на машине devbox. Всё Godot-шное — только там, на Mac Godot не запускают.

## Рабочее место

- Рабочая копия — git worktree `~/wt-godot` на devbox, ветка `agent/godot` (от `agent/netrun`). Проект — `~/wt-godot/netrun`.
  Правишь **только там** (по ssh или через MCP), не в `~/megablock10` — там постоянно чужая ветка.
- Редактор с плагином: `ssh devbox 'bash ~/wt-godot/scripts/devbox-godot-ai.sh status'`; нет — `start` (ждёт подключения плагина,
  ≈ 40 с), первый раз — `setup`. `stop` снимает из `project.godot` строки плагина. Редактор при открытии сам переписывает
  `project.godot` (комментарии, значения по умолчанию) — если настройки проекта не менялись, перед коммитом
  `git -C ~/wt-godot checkout netrun/project.godot`; иначе проверь, что в diff нет `godot_ai`, `_mcp_game_helper`, `main_run_args`.
- MCP-инструменты `godot-ai` приходят из `.mcp.json` (ssh + `uvx godot-ai attach`). Не появились — редактор не запущен.
- Тяжёлое и долгое (весь набор gdUnit4) — отвязанно, `devjob start <имя> '<команда>; echo rc=$?'` (skill `devbox`).

## Как проверять — по порядку, не пропуская

1. **Тесты — gdUnit4**, не `test_run` плагина (он ищет свои сьюты и тесты проекта не видит):
   `ssh devbox 'cd ~/wt-godot && netrun/tools/gdunit.sh [res://tests/файл_test.gd]'`. Код 0 — зелёно, 100 — есть упавшие,
   101 — предупреждения (CI красит и их). Отчёты — `netrun/reports/` (читать по ssh, не пересказывать по памяти).
   Правка логики — сначала тест, который падает, потом код.
2. **Структура сцены** — `scene_get_hierarchy`, `node_*`, `script_*`, `scene_save`; правку подтверждай чтением обратно.
3. **Вид и поведение** — сервер мира отдельно (`godot --headless --path ~/wt-godot/netrun -- --tokens=t1:alice --exit-after=600`,
   порт 7777; одновременно один), затем `project_run` (аргументы клиента — плоский, `127.0.0.1:7777`, токен `t1`: заданы скриптом),
   `editor_screenshot {source:"game"}` и `logs_read {source:"game"}`; в конце `project_manage {op:"stop"}` и остановить сервер.
   Журнал игры: `~/.local/share/godot/app_userdata/Мегаблок 10- Сеть/logs/`.
4. **VR-проверки** (OpenXR, трекинг, кадр на Pico 4) на devbox недоступны — не утверждай, что они пройдены.

## Правила

- Решения владельца (`docs/netrun.md`, память проекта) не пересматривать: смерть через мастера, Мост предметов не создаёт, и т. д.
- Один Gradle и один сервер мира/редактор на машину; порты 8000/9500 (плагин), 7777 (мир), 7410/7411 (Мост) не занимать чужим.
- Не искать процессы `pkill -f`/`pgrep -f`/`ps | grep` по строке, которая есть в самой ssh-команде — совпадёт с ней и убьёт сессию;
  редактор останавливает скрипт по pid-файлу.
- Плагин (`addons/godot_ai/`) в репозиторий не коммитить; `reports/` и `.godot/` тоже.
- Коммиты — на русском, что и **почему**, в ветку `agent/godot`; в `main` не трогать. Принести на Mac:
  `git fetch devbox agent/godot`.
- Отчитывайся фактами: что запускал, код выхода, сколько тестов упало. «Проверено» — только после зелёного gdUnit4.
