# Описание PR

Без вступлений, коротко, словами из `GLOSSARY.md`.

```markdown
## Что

<1–3 строки: что меняется и почему (какой сбой, чьё решение). Если помогает — дерево файлов, схема или кусок диффа.>

## Доказательство

- **До:** <падающий тест / строка журнала / цифра bench / кадр>
- **После:** <зелёный тест / строка / цифра / кадр>
- Проверено: <verify.sh --full, dev.sh test --all, очки — что именно>; не проверено: <честно>.

## Опасность слияния

**Дверь:** <двусторонняя — откат одним revert | односторонняя — миграция БД, смена формата/версии контракта, удаление данных или файлов, которые нужны кому-то ещё>

**Радиус:** <одно-два слова: вид Сети, деньги, протокол Моста, e2e, CI, только документы…>

<если односторонняя или радиус широкий: порядок слияния, пара с PR M, что предупредить у соседей>

🤖 Generated with [Claude Code](https://claude.com/claude-code)
```

## Двери

- **Двусторонняя:** код, шейдеры, ручки за умолчанием, документы, скрипты — откат одним `git revert` без последствий.
- **Односторонняя:** миграции и схема БД коллектора, формат записей мира и сообщений Моста, версии в `/api/capabilities`, QR-формат, удаление моделей/ассетов, на которые ссылается другой код, всё, что уже ушло на телефоны игроков. Для неё — порядок по правилу контракта из `CLAUDE.md` и пометка в «готово к слиянию».

Строку «Дверь / Радиус» повторите в сообщении Pipeline «готово к слиянию» — по ней собирается поезд.
