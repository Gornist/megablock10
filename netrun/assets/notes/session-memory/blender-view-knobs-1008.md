Состояние на 08.10.2026 (main 2a7f25f, влиты #130 #135 #140 #143 #148 #153 #155 #164). Владелец на очках (Pico 4) идёт замерами П5/П6; Pipeline ставит стенд, Godot вносит строки в [assets] конфига. Все ручки по умолчанию «как раньше»; список и таблица «жалоба → ручка» — `netrun/assets/ARCHITECTURE.md` §21.

**Решения владельца по виду (на очках):** штрихи окружения убрать совсем (`streak_keep=0`), точки окружения убрать (`point_keep=0`), «лава-лампа» на горизонте/краях неуместна (`drift_static`, `flat_light`, `mist_alpha`), нравится «вуаль у плит потолка» — полупрозрачная завеса по бокам плиты (сделана такая же ВВЕРХ у плит пола и дальнего пола: `tile_glow`, `tile_glow_h`), глитч-руки читаются (частица вполовину: `HandView.glitch_scale` 0,5, `glitch_gain` 1,8; рука не уменьшалась), лесенка граней остаётся (MSAA 4× её снимает, но 72 Гц не держит).

**Подтверждено измерением:** «лава-лампа» после drift_static = шум света вдоль рёбер плит solid_dark (edge_drift, edge_uneven), не дымка; профиль ребра колонны на очках = гладкая «палатка» циана без белого; edge_soft, fringe_on=false, edge_glow=1 белую линию не убрали; `centroid` в Godot-шейдерах нет.

**Только гипотеза (ждёт замера 6–8):** белая мерцающая линия по середине ребра колонны при MSAA = излом линейного градиента на пике (`edge_round=1` — главный кандидат). Настольный MSAA 4× её не воспроизвёл.

**Открыто:** прототип «волюметрик из частиц» (`dust`, #148, выключен) на очках не смотрели; перерисовка завесы на Pico не мерилась; цвета 2D-деки.
