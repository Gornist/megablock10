Архив владельца «Cyberpunk 2077.zip» (23 PNG 2560×1440, `photomode_07102026_*`), разобран 08.10.2026. Исходники — только у владельца (~116 МБ); в памяти — контактные листы 2×2: `memory/netrun-refs2/sheet_aa..af.jpg`, порядок кадров — `memory/netrun-refs2/ORDER.txt` (старые референсы 1–6 — `memory/netrun-refs/*.webp`, это другая сторона: туман и стены из штрихов).

Что на них (отличается от нашего вида «чёрные плиты + неоновые рёбра»):
- Всё — **плотное облако точек**: пол — густая «пыль» мелких точек, постройки — поверхности из точек, плотность по освещённости; рёбер из света почти нет, силуэты читаются плотностью. Валуны/«кучи данных» — округлые оболочки из точек с косой штриховкой (линии скана). Лестничного алиасинга нет: края стохастические.
- **Цвет массы — тусклая стальная бирюза**, не неон: яркие точки ≈ (45,118,141), среднее по участку (22,54,68); белёсый — только редкие акценты (балки, проём). Наш PAL_DIM 2d6b78 близок; наш PAL_CYAN 18e6ff на порядок ярче.
- **Фон — не чистый чёрный и не бирюзовый**: пол пустых кадров нейтральный (17–20,17–20,16–21), в плотных кадрах (22,31,36). Чёрного <12 яркости: 0%, но 70–93% пикселей темнее 40: освещено только 10–30% кадра (среднее по кадру (21,30,35)).
- **Красный = человек/угроза**: голограммный человек — гладкое полупрозрачное тело (157,35,62), ядро розово-белое (220,126,161), Fresnel-кромка и горизонтальные «рёбра»; вдали — маленькие красные фигурки.
- **Красный «эквалайзер»** (кадры 231913/231944): горизонтальная яркая линия с вертикальными смазами вверх/вниз, малиново-розовая — эффект перехода/обнаружения.
- Кадр 232501 в архиве — пустой зелёный (брак съёмки).

Предложения (не решения владельца): пыль как шейдер на solid_dark (без геометрии и перерисовки); палитра массы — PAL_DIM, неон — акцент; красный человек как Fresnel-оболочка с рёбрами; красный эквалайзер — для обнаружения/поимки.
