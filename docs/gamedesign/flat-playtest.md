# Плоский клиент для домашнего плейтеста

Часть [геймдизайна](README.md). Решения владельца 17.10. Зачем: проверять понятность стелса и взлома на людях без гарнитуры, не дожидаясь очков.
Игрокам ларпа плоского режима по-прежнему нет ([../netrun.md](../netrun.md)): эта сборка — только для тестеров.

## 1. Что решено

| # | Решение | Почему |
|---|---|---|
| 1 | Тестеры играют дома на своих ПК; сборка только под Windows | у тестеров Windows; одна платформа — одна проверка |
| 2 | Один exe, сервер мира зашит внутрь: одиночная игра без devbox и сети | тестеру нечего настраивать |
| 3 | Вид от первого лица, как в очках; изометрии игроку нет | сверху видна вся доска — стелс лёгкий, цифры не переносятся на очки. Изометрия — позже, как вид наблюдателя для мастера |
| 4 | Ход — только телепорт до 2 клеток (досягаемость 2,2), поворот шагом 45° (Q/E), мышь — осмотр; WASD нет | свободная ходьба ломает клетки и такт ([time-and-movement.md](time-and-movement.md)) |
| 5 | Прицел телепорта по центру экрана; промахи прицела — в журнал | мышь точнее руки: разницу принимаем, но меряем, чтобы сравнить с очками |
| 6 | Состав: учебный узел → забег Архив BASE → Серверная HARD → Ядро NIGHTMARE (стенд П7/П8) | забег одинаков у всех тестеров |
| 7 | Дека зашита, как фикстура стенда П7: Призрак, RAM 14, демоны П5/П6; экономики нет, итог — добыча цифрами на экране | дома нет телефона и Моста |
| 8 | Обучение: учебный узел с табличками, подсказки клавиш в углу (H — скрыть), одна картинка управления при первом запуске; отдельной инструкции нет | если без инструкции непонятно — это находка |
| 9 | При запуске — экран «Наденьте наушники» | ICE слышно раньше, чем видно ([levels.md](levels.md) §2 п. 2); без звука цифры не сравнить |
| 10 | Перезапуск забега без ограничений; журнал — каждой попытки; анкета — только после первой | первая попытка — замер понятности, повторы — замер обучения |
| 11 | Номер сборки на экране и в каждом журнале; новая сборка — новый exe | журналы разных сборок не смешиваем |
| 12 | Тестеры: 3–5 человек, из них хотя бы двое не играют в игры; сборку и журналы собирает владелец | протокол [../netrun-playtest.md](../netrun-playtest.md) |

## 2. Журнал

- Пишется в `Документы\Мегаблок10\runs\<дата-время>-<сборка>\` — одна папка на попытку (папка программы бывает закрыта на запись).
- На экране итога: путь, кнопка «Открыть папку» и «пришлите этот файл»; тестер шлёт один zip.
- Внутри — тот же журнал забега, что на стенде очков (такты, поимки, взломы, тревога), плюс промахи прицела и ответы анкеты.

## 3. Анкета (в exe сразу после первого забега, ответы — в журнал)

1. Понял ли, почему тебя заметили? (1–5)
2. Понял ли замок к второму взлому? (да / нет / не дошёл)
3. Где заблудился? (строка)
4. Было ли «нечестно» — где? (строка)
5. Что раздражало больше всего? (строка)
6. Сыграл бы ещё раз? (да / нет)

## 4. Как читать цифры

Плоская сборка проверяет **понятность** (замок, телеграф ICE, почему заметили) — это переносится на очки. Время и точность прыжков не
переносятся (мышь точнее, нет укачивания): сравниваем с журналами очков, но решения по числам окон и темпа принимаем по очкам.
