# Серверная HARD: объекты кадра (server_room 8x8; в скобках server_room_hard10)

Кадры: `objects-server-room.png` (сверху, главный), `-entry.png` (с входа), `-back.png` (от северной стены на юг); то же `objects-hard10*.png`.
Клетка = блок карты (sx, sz), блок 2x2 м, север сверху. Роль — по коду `netrun/server/`, `shared/`, а не по виду.

| № | Объект | Модель / символ | Клетка | Роль в правилах | Роль есть? |
|---|---|---|---|---|---|
| 1 | Хранилище внешнее (ring outer) | props/vault.glb, `V` | (0,0) (7,0) [(0,0) (9,0)] | цель взлома, внутри шард; для внешних layout_check требует окно патруля (outer_min) | да |
| 2 | Хранилище внутреннее (ring inner) | props/vault.glb, `v` + запись vaults | в 8x8 нет [(3,0)] | то же; inner не входит в проверку двух непересекающихся путей (layout_bots) | да |
| 3 | Площадка хранилища | props/hack_pad.glb, клетка `pad` | (0,1) (7,1) [(0,1) (9,1) (3,1)] | место взлома: привязка телепорта (VAULT_SNAP_RADIUS), в окне патруля проверяется именно она; взлом дальше BREACH_REACH 3 м от хранилища не начнётся | да |
| 4 | Корпус панели взлома | props/hack_panel.glb | рядом с площадкой | сервер не читает; только экран-корпус для панели взлома клиента | только вид |
