# Карточки Godot: формат W×H и плоская сборка для тестеров (Game, 17.10)

Решения владельца 17.10 (допрос — Game): `docs/gamedesign/levels.md` §1.1 и `docs/gamedesign/flat-playtest.md`.

## G1. Формат раскладки W×H (до П9)

- Карта раскладки — любой W×H (сейчас ровно 8×8); предел площади по тиру узла: BASE ≤ 64, HARD ≤ 100, NIGHTMARE ≤ 144 клеток карты (2 м).
  Больше — ошибка LayoutCheck.
- Под W×H: чтение раскладки (`layout_data.gd`), LayoutCheck (окна, входы, пути, тупики), боты, клиент (пол, сетка, стены, кадр на Pico — замер
  на самой большой карте), soak.
- Новая раскладка `server_room_hard10` — Серверная HARD 10×10: 3 Стража, Маяк + Датчик (2), укрытия 20–30 % клеток; все правила §2
  (окна ≥ 8, цикл ≥ 2 × порог, вход безопасен, уход 2–4 прыжка). Черновик карты — пришлите мне, правлю замысел до данных.
- Стенд П9: та же цепочка, что П8, но Серверная HARD — сначала 8×8, потом 10×10 (или два забега); в журнале — время до хранилища,
  поимки, взломы по каждому размеру.
- Ядро 12×12 — **не делать**, пока нет итога П9.

## G2. Плоская сборка Windows для тестеров (по flat-playtest.md §1–3)

- Один exe: сервер мира внутри, одиночная игра, без devbox и сети; экспорт Windows.
- Вид от первого лица, как в очках; изометрии нет.
- Управление: только телепорт (досягаемость 2,2, прицел по центру экрана), поворот 45° Q/E, мышь — осмотр; WASD (`--walk`) в сборке выключен.
  Взаимодействие с декой и панелью взлома — ваше решение по удобству мыши, правило игры то же.
- Состав: учебный узел → Архив BASE → Серверная HARD → Ядро NIGHTMARE; дека — фикстура стенда П7 (Призрак, RAM 14, демоны П5/П6).
- Экраны: «Наденьте наушники» и картинка управления при первом запуске; подсказки клавиш в углу (H — скрыть); итог забега — добыча цифрами,
  путь к журналу, «Открыть папку».
- Журнал: `Документы\Мегаблок10\runs\<дата-время>-<сборка>\`, тот же формат, что у стенда очков, плюс промахи прицела и анкета.
- Анкета (6 вопросов, flat-playtest.md §3) после первого забега; перезапуск без ограничений.
- Номер сборки на экране и в журнале.
- `docs/netrun.md` («плоского режима для игроков нет») — поправьте у себя: игрокам ларпа по-прежнему нет, тестерам — есть.
