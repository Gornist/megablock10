## Ш1 — клетки и укрытия (К1 + К2)

1. Общий код клеток (`netrun/shared/`): `cell_m = 1.0` одним параметром; узел 16×16 (x −8…8, z −14…2; `NodeLayout.cell_center` есть); занятость;
   досягаемость — центры ≤ 4,5 м; отрезок прыжка не проходит сквозь занятые; supercover-линия взгляда (угол между двумя клетками закрыт, только
   если заняты обе). Нынешние колонны `node_layout.gd` → занятые клетки. Тесты gdUnit на чистых функциях.
2. ICE не видит сквозь занятые клетки **уже в нынешнем непрерывном времени** (`ice_brain.gd`: видимость = конус + линия взгляда общего кода).
3. Телепорт: дуга притягивается к достижимой клетке (рамка клетки вместо кольца); серая рамка со значком причины; «ждать» — дуга на свою клетку;
   хранилище — площадка лицом к нему; сервер проверяет клетку (`net_server.gd`, `teleport_snap`). Журнал `rig.teleport cell=… ok=…`.
4. Приёмка: тесты; плоский стенд — стоя за колонной на линии Стража, игрок не замечен; `dev.sh test --all` зелёный. PR.

## Ш2 — такт (Т1 + Т2)

1. Часы узла: `graph.json settings.time_mode` = `tick` (по умолчанию) | `realtime`; `tick_window_sec` 5,0, `tick_min_interval_sec` 0,6. Ход =
   прыжок, «ждать», взять, начать взлом/заряд (Т1–Т8 из 3.1); WeGo для нескольких нетраннеров; панель не держит такт (Т3); тактов нет без
   нетраннеров (Т8 — и `rest()` по-прежнему). «Один ход за такт» вместо перезарядки телепорта 1,2 с.
2. ICE на клетках, числа — по 2.0: Страж 2 клетки/такт по маршруту, зрение 6 / 8 клеток, фокус ±25°, периферия до ±50°; осведомлённость 0–6:
   Взгляд (1–2) — стоит и смотрит, Проверка (3–4) — идёт 2 клетки/такт, Поиск (5–6) — 4 клетки/такт, Захват — центры ≤ 2 м в Поиске → выброс.
   Фокус +2 за такт, периферия +1, не видно — −1 (ice.md 2). Шаг ICE на клиенте — плавно 0,4 с. Black ICE в `tick` — пока прежняя логика,
   пересчитанная в такты по метрам (полная переработка — волна Б).
3. Телеграф: сервер каждый такт шлёт намерения ICE (клетка, направление, состояние); клиент — свет зрения на полу (фокус ярче, периферия тусклее),
   стрелка следующего шага, цвет «глаза» по состоянию, цвет рамки прицела (зелёный / жёлтый / красный — прогноз на следующий такт, общий код);
   «вдох» перед тактом по окну (пульс света 0,5 с). Красная рамка «залипает» 0,4 с (С9).
4. Формат сообщений мира — новые поля так, чтобы старый клиент не падал; Opus-ревью диффа сообщений; `docs/netrun-*.md`.
5. Приёмка: детерминированные тесты (ход → такт; окно; два нетраннера; панель); бот-прогон 10 мин без ошибок; на модели П1 — «?» → Захват не
   раньше 3 тактов, уход за колонну из Взгляда сбрасывает. PR.
