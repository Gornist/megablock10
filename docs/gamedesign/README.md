## Столпы

Каждое правило в документах проверяется этими семью принципами. Если правило с ними спорит — правим правило.

1. **Сложность — в решениях, а не в руках.** Ни точность прицела, ни скорость реакции не решают исход: игрок сидит в очках, телепорт неточный,
   играют не только геймеры. Сложно должно быть *придумать*, а не *успеть нажать*.
2. **Ничего не мгновенно.** У любой угрозы — предупреждение и хотя бы один ход на ответ. Смерть персонажа — только цепочка ошибок.
3. **Видно, почему.** Если ICE изменил поведение, игрок сразу понимает причину; если взлом провалился — видно, где ошибка
   (правила Mark of the Ninja, они уже в [../netrun.md](../netrun.md)).
4. **Время — ресурс.** Каждая лишняя минута в узле повышает риск (Invisible Inc., Shadowrun): забег не «зачищают», из него уходят вовремя.
5. **Награда идёт за усилие и риск**, а лучшая награда создаёт игру другим игрокам (компромат, ключи, заказы), а не только эдди.
6. **Один движок, два интерфейса.** Взлом и демоны одинаковы на телефоне и в очках; Сеть добавляет мир вокруг, а не другие правила.
7. **Сидя и комфортно.** Камера движется только по воле игрока; опасность передают свет, звук, вибрация и среда.

## Диагноз: почему сейчас быстро и «мгновенно» (состояние до 06.10)

### Взлом решается без планирования

Причины (по коду `rules/…/BreachEngine.kt`, `BreachAttempt.kt`, `BreachParams.kt`, `netrun/server/node/vault_breach.gd`):

1. **Порядок цепочек выбирает игрок.** Извлечение ставится первым и собирается за 2–3 клика; `BreachResult` даёт PARTIAL при любом совпадении,
   а PARTIAL с совпавшим Извлечением — это уже добыча. Остальные демоны — бонус.
2. **Сетка щедрая.** Алфавит — 6 кодов, буфер = вся RAM (6–13), стартовый демон «Datamine V1» — 2 кода. У стартовой BASE-сетки медиана
   ~250 решающих путей. Ловушки раскидываются случайно и вне пути; порченые коды — только на NIGHTMARE.
3. **Провал бесплатный.** После FAIL остывания нет (`docs/netrun-deck-design.md` 7.3), повтор сразу; в Сети растёт только тревога узла на 0,3.
4. **Таймер не ограничивает.** 45/60/75 с при 2–8 нужных нажатиях.

Модель ([model/breach_model.py](model/breach_model.py), 400 сеток на строку): «жадный» смотрит на один ход вперёд, «думающий» — на три.

| Сейчас | Буфер | Жадный берёт добычу | Думающий |
|---|---|---|---|
| BASE 5×5, демон из 2 кодов, RAM 6 | 6 | 98 % | 100 % |
| HARD 6×6, демоны 3+3, RAM 8 | 8 | 88 % | 100 % |
| NIGHTMARE 7×7, демоны 3+4, RAM 10 | 10 | 89 % | 99 % |

Разницы между «тыкать» и «думать» почти нет — значит, навык в взломе сейчас не нужен. Что с этим делать — [breach.md](breach.md).

### ICE срабатывает «мгновенно»

По коду `netrun/server/ice/ice_brain.gd`, `trace/trace_meter.gd`, `shared/node_layout.gd`:

- Все узлы — **одна комната 16×16 м** (`NodeLayout`: «общая комната у всех узлов»). ICE видит на **12 м** конусом **100°**, при тревоге —
  до 18 м. **Колонны зрение не загораживают** («Колонны только для глаз»): спрятаться негде.
- На виду осведомлённость растёт на 0,5/с — через **2 с** поиск, бег 2,5 м/с, касание 1,5 м — выброс; trace растёт на **8/с** — TRACE через
  ~6 с, выброс через ~12 с. В плоском прогоне неподвижного игрока выбрасывали через ~10 с (`docs/netrun-stage1-results-flat.md`).
- Взлом держит игрока у хранилища 45–75 с, а патруль идёт через центр комнаты: без Призрака это почти верный выброс. С Призраком — проблемы нет:
  Призрак III — 45 с невидимости при перезарядке 50 с (`data/daemons/effects/GHOST.json`), он же прячет и от охоты Black ICE.
- Black ICE охотится с уровня TRACE прямо по позиции, без зрения, 2 м/с; касание — флэтлайн. В комнате 16 м — не больше 10 с.

Ступени (патруль → подозрение → поиск) есть, но проходят за 2 секунды и снаружи почти неразличимы. А телепорт неточный: игрок не может
«встать в 10 см от конуса» — он промахнётся. Что с этим делать — [time-and-movement.md](time-and-movement.md) и [ice.md](ice.md).

### Награда не связана с усилием и риском

- Эдди за взлом символические: 1–3 / 4–6 / 7–10, Майнер +15/30/60 (`rules/…/ContainerEddies.kt`).
- Ценность шарда задаёт мастер вручную (`moneyAmount`, текст); риск NIGHTMARE (дека, персонаж) нигде не учтён.
- Стартовый баланс персонажа и цены задаёт мастер — общей шкалы ценности в проекте нет.

Что с этим делать — [economy.md](economy.md).

### Поправка к первой устной оценке (6 октября)

В первом ответе владельцу было «замок хранилища снижает долю добычи у жадного игрока с 90 % до 28 % на HARD и с 93 % до 7 % на NIGHTMARE».
Эти числа посчитаны для случая, когда Извлечение стоит **после замка и ещё одного демона**. Если игрок ставит Извлечение сразу за замком
(он так и сделает), на HARD с одним демоном — 43 %, с двумя — 72 %; на NIGHTMARE — 16 % и 52 % ([breach.md](breach.md), раздел 4).
Вывод не меняется (замок — главный рычаг), но сила рычага скромнее, и лишние демоны в деке дают жадному игроку запас кликов на ошибку.

## Словарь

| Термин | Значение |
|---|---|
| **Клетка** | квадрат 1×1 м пола узла; узел по умолчанию 16×16 клеток, раскладка любого размера до 24×24 |
| **Клетка карты** | 2×2 м (как модули окружения, `netrun/assets/models/MANIFEST.md`); узел по умолчанию 8×8 клеток карты |
| **Такт** | шаг времени узла: каждый ICE делает один шаг своей программы, сервер считает видимость |
| **Ход** | действие нетраннера, которое двигает такт: телепорт, «ждать», взять, запустить демона, начать взлом, вскрыть барьер |
| **Окно такта** | сколько секунд такт ждёт ходов, прежде чем наступить сам (5 с) |
| **Осведомлённость** | счётчик 0–6 у пары «ICE — нетраннер»: сколько этот ICE «уверен», что видел нетраннера |
| **Trace** | 0–100 у нетраннера: насколько отслежено его соединение; живёт весь забег, во всех узлах |
| **Тревога узла** | 0–100 у узла, четыре уровня: насколько узел «на взводе»; общая для всех нетраннеров узла |
| **Замок хранилища** | цепочка кодов хранилища (контейнера), которую нужно собрать раньше Извлечения |
| **Приманка** | порченый код, поставленный там, куда тянется невнимательный игрок; виден по лёгкому мерцанию |
| **Ожог** | счётчик захватов Black ICE за забег; три — флэтлайн |
| **Жадный / думающий / решатель** | модели игрока в [model/breach_model.py](model/breach_model.py): 1 ход вперёд / 3 хода / полный перебор |
