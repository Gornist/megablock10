# Бриф: подбор VR-очков и софта для «Сети»

Этот документ — задание для агента, который подбирает конкретные версии железа и софта для VR-клиента «Сети». Он
самодостаточен: всё нужное для работы — здесь, подробности — в [netrun.md](netrun.md) (план проекта) и
[network-spec.md](network-spec.md) (сеть площадки).

## 1. Что мы делаем

«Мегаблок №10» — киберпанк-LARP примерно на 100 игроков. У каждого игрока Android-телефон с приложением игры (чат, звонки,
кошелёк, предметы, взлом узлов по QR), у мастеров — сервер-коллектор с дашбордом на локальном мини-ПК. Вся игра идёт в
**закрытой локальной сети без интернета** (UniFi, один SSID).

«Сеть» — новая часть игры для нетраннеров (до ~10 человек из ~100). Нетраннер садится на стул у стойки-терминала в своей
локации площадки, телефоном сканирует QR стойки и сдаёт «деку» программ, надевает **автономные VR-очки** и оказывается внутри
3D-киберпространства: крадёт данные, обходит защиту (ICE), уходит, пока его не отследили. Добыча возвращается на телефон.
Забег — около 30 минут, **только сидя**. Всего стоек до 10, по разным локациям.

Архитектура (подробно — [netrun.md](netrun.md)):

- **Клиент в очках** — Godot 4, стандартный OpenXR, APK для Android. Ничего не хранит и не решает: ввод и картинка.
- **Сервер мира** — Godot без экрана на локальном мини-ПК (x86, Linux). Клиенты подключаются к нему по **Wi-Fi площадки**
  (ENet, UDP). Игрового ПК между очками и сервером нет.
- **Мост** — Kotlin-сервис на том же мини-ПК; с очками напрямую не общается.

## 2. Задача

Подобрать и обосновать **конкретную конфигурацию** очков и всего софта вокруг них под требования ниже:

1. **Модель очков** в семействе Pico 4: Pico 4, Pico 4 Enterprise, Pico 4 Ultra, Pico 4 Ultra Enterprise или новее, если есть
   на момент исследования. Какую брать и почему.
2. **Прошивка (Pico OS)**: какую версию закрепить на весь парк, как поставить её без интернета на площадке.
3. **Godot**: версия движка, версия плагина OpenXR Vendors (нужен ли он вообще), версии Android SDK / NDK / JDK / build-tools
   для экспорта, шаблоны экспорта. Совместимость версий между собой и с выбранной прошивкой.
4. **Рендерер и настройки проекта для XR**: Mobile или Compatibility на этом чипе, частота обновления (72/90 Гц), фовеальный
   рендеринг, разрешение отрисовки, что из этого реально работает в Godot на Pico.
5. **Управление парком**: режим разработчика, установка APK через adb, режим киоска или автозапуск (штатный Enterprise-инструмент
   или самодельный, например PicoKiosk), отключение обновлений, сна, всплывающих окон.
6. **Аксессуары и количество**: зарядки, кабели, запасные контроллеры, питание контроллеров, сменные накладки, проставки для
   очков для зрения, при необходимости — ИК-подсветка для трекинга. Список закупки с количествами и ориентировочными ценами.

Первый приоритет: **что купить сейчас на 1–2 экземпляра для прототипа**. Прототипные очки должны совпадать с будущим парком по
модели и прошивке, иначе результаты прототипа не переносятся.

## 3. Требования

### Жёсткие (конфигурация, которая их не выполняет, не подходит)

| # | Требование | Почему |
|---|---|---|
| Ж1 | Автономные Android/OpenXR-очки с 6DoF-трекингом головы и двух контроллеров | клиент — APK Godot, без ПК |
| Ж2 | Godot 4 экспортирует APK и приложение работает через **стандартный OpenXR**; специфичные API Pico — только там, где без них нельзя | один проект, без привязки к вендору |
| Ж3 | **Работа полностью без интернета**, сколько угодно дней подряд: без периодической проверки аккаунта, без окон «нет подключения», мешающих игре. Интернета на площадке нет, **в том числе для обслуживания** | решение владельца |
| Ж4 | Всё, что требует интернета (активация, аккаунт, режим разработчика, прошивка), делается один раз до выезда; прошивку можно поставить офлайн | см. Ж3 |
| Ж5 | Wi-Fi 5 ГГц к сети UniFi без интернета: очки **не отключаются от Wi-Fi из-за «нет интернета»** и держат UDP-соединение с сервером в локальной сети | сервер мира только в локалке |
| Ж6 | Установка своего APK без магазина (adb, режим разработчика) | приложение не публикуется |
| Ж7 | Сидячий режим: контур безопасности настраивается один раз на стойке и **не требует перенастройки** после сна, перезагрузки и замены очков на запасные на той же стойке (или известен надёжный обходной путь) | игрок не должен ничего настраивать |
| Ж8 | После сна (сняли очки) и после перезагрузки очки возвращаются в наше приложение без действий в системном меню (штатно или обходным путём) | «сел, надел, играешь» |
| Ж9 | Стабильные ≥ 72 кадров/с в Godot на этом чипе для простой сцены с светящимися материалами | в VR просадка = укачивание |
| Ж10 | Парк из **13–15 одинаковых экземпляров** (10 рабочих + 3–5 запасных) одной модели и одной прошивки можно купить | ротация и замена |

### Желательные

| # | Требование |
|---|---|
| П1 | Цена около 20–25 тыс. ₽ за очки (ориентир владельца); если Enterprise-версия заметно дороже — показать, что она даёт за разницу |
| П2 | Батарея: 30-минутный забег с запасом, быстрая зарядка между забегами; возможность играть от внешнего питания сидя |
| П3 | Трекинг устойчив при слабом свете, неоновой и ИК-подсветке (тёмные киберпанковские локации) |
| П4 | Можно быстро взглянуть на комнату через камеры (passthrough), не выходя из приложения, — штатно или через OpenXR-расширение, поддержанное в Godot |
| П5 | Модель поддерживается производителем ещё хотя бы пару лет: обновления прошивки, запчасти, наличие в продаже |
| П6 | Пространственный звук в очках без наушников достаточно громкий для шумной локации (или нужны наушники — тогда какие) |
| П7 | Контроллеры: чем питаются, сколько держат, можно ли аккумуляторы |

## 4. Уже решено — не пересматривать

- Семейство **Pico 4**, автономные очки, без ПК. Играют **только сидя**, room-scale не нужен.
- **Godot 4, стандартный OpenXR**. Движение — левый стик, поворот рывками — правый; контроллеры, без hand tracking в MVP.
- Играть в VR могут **все** нетраннеры — плоского режима для игроков нет.
- **Интернета на площадке нет** и не будет, внешнего канала для обслуживания тоже нет.
- Стойки — **по локациям**, очки — клиенты общего Wi-Fi площадки.

Если какое-то жёсткое требование в семействе Pico 4 невыполнимо, **скажите об этом прямо** и предложите минимальное изменение (другая
версия, Enterprise, аксессуар, обходной путь). Другие марки очков предлагать только если Pico 4 не проходит, с объяснением, какое
требование нарушено; учтите, что многим другим очкам для работы нужен онлайн-аккаунт.

## 5. Что мы уже выяснили (проверьте актуальность на сегодня)

- С Godot 4.6 экспорт на Android-очки работает без плагина OpenXR Vendors; плагин «рекомендуется», даёт вендорские
  расширения. [Godot: Deploying to Android](https://docs.godotengine.org/en/4.7/tutorials/xr/deploying_to_android.html),
  [OpenXR Vendors](https://github.com/GodotVR/godot_openxr_vendors)
- Документация Godot теперь рекомендует рендерер **Mobile** и для автономных очков (раньше — Compatibility); на Quest 3 жалуются
  на ошибки драйверов Vulkan. Ubershaders и предкомпиляция конвейеров (меньше рывков при первой отрисовке материала) есть только
  в Mobile и Forward+. [Setting up XR](https://github.com/godotengine/godot-docs/blob/master/tutorials/xr/setting_up_xr.rst),
  [W4 Games](https://www.w4games.com/blog/w4-games-news-1/where-every-millisecond-counts-optimizing-godot-for-standalone-xr-159),
  [Pipeline compilations](https://docs.godotengine.org/en/stable/tutorials/performance/pipeline_compilations.html)
- Трекинг Pico 4 теряется в темноте, от ИК-подсветки и гирлянд, перед голыми стенами («Limited Terrain Features»).
  [Reddit](https://www.reddit.com/r/PicoXR/comments/11q9jj5/new_pico_4_wont_track_anymore_limited_terrain/),
  [VRcasts](https://vrcasts.com/guides/vr-low-light-tracking-tips/)
- Батарея Pico 4 — около 2 ч, в тяжёлых сценах около 1,5 ч; зарядка во время работы медленная или останавливается, полная —
  около часа. [Pico 4 FAQ](https://www.manualslib.tech/guide/739943/pico-4-faq-manual.html)
- Автозапуск при включении и режим киоска — штатно только на Enterprise-версиях; у обычной Pico 4 система блокирует запуск
  сторонних приложений по загрузке. Есть самодельный PicoKiosk (скрипт через adb).
  [pico-webxr-kiosk](https://github.com/robinhuse/pico-webxr-kiosk), [PicoKiosk](https://github.com/it03lab-ops/PicoKiosk),
  [PICO Business Suite](https://business.picoxr.com/global/software/business-suite)
- Прошивку можно обновить офлайн: папка `dload` в памяти очков, «Offline Update». [pico4.wiki](https://pico4.wiki/guides/ota/)

**Не проверено и нужно выяснить:** нужен ли аккаунт и интернет для первичной настройки и режима разработчика; ведут ли себя
очки нормально неделями без интернета; не отключаются ли от Wi-Fi без интернета; сохраняется ли сидячий контур после сна и
перезагрузки и при замене очков; возвращаются ли в приложение после сна; стабилен ли Vulkan (рендерер Mobile) в Godot на этом
чипе; поддерживает ли Godot фовеальный рендеринг и passthrough на Pico; актуальная линейка и наличие Pico в России на сегодня.
