## Шаги
1. **AA1 — `RenderConfig`:** класс чтения [render] (`load_file`/`from_config`/`log_fields`), тест на парсинг (ошибочные и граничные значения), файл `netrun.cfg` — тот же путь, что у NetConfig (посмотри константу).
2. **AA2 — применение в XR:** в `xr_rig.start_xr()` после `use_xr = true`: `get_viewport().msaa_3d` из конфига (0→DISABLED, 2→2X, 4→4X); масштаб `iface.render_target_size_multiplier = scale` (OpenXRInterface, если свойство есть); `iface.foveation_level` / `foveation_dynamic` (свойства OpenXRInterface Godot 4.7; проверь через `api_manage` не нужно — используй `"foveation_level" in iface`). Применять один раз; в журнал строка `render msaa=… scale=… foveation=… dynamic=…` при старте. Плоский клиент (без XR): msaa_3d из конфига тоже. Тест на чистую часть (маппинг значений) — без XR.
3. **AA3 — вид глазами Pico:** `EyePresets`: `EYE_VIEWPORT := Vector2i(2160, 2160)` (на глаз), `FOV_DEG = 100.0`; `tests/foyer_preview.gd`: кадры «глаз» снимаются Viewport'ом такого размера с `msaa_3d`, как в клиенте (`RenderConfig` по умолчанию; флаг `--msaa=0|2|4` в `OS.get_cmdline_user_args()` для A/B), кадры «top…» — как сейчас. Тест `eye_presets_test` на константы. Сетка `dev.sh shot` должна по-прежнему собираться ≤ 1024 px (проверь запуском).
4. **AA4 — текст (Label3D):** `client/ui/teleport_aim.gd` (pixel_size 0.004, font_size 56), `client/ice_view.gd` (96/0.006) и остальные Label3D клиента (`grep -rn Label3D client`): включить `texture_filter` = LINEAR_WITH_MIPMAPS_ANISOTROPIC где ещё нет, `font_size` ×2 с `pixel_size` ÷2 (крупнее растр, тот же размер в мире), `outline_size` пропорционально; шрифт не тоньше 2 px обводки; MSDF у Label3D — только если шрифт проекта поддерживает (`FontFile.multichannel_signed_distance_field = true` в import-файле — НЕ трогай .import, опиши в отчёте, как включить). Тест не нужен, кроме чистой константы размеров, если вынесешь.
