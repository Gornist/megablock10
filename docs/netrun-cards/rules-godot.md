# Общие правила исполнителя — Godot (netrun/), проект «Мегаблок №10»

Рабочая копия и ветка названы в карточке. Работаешь ТОЛЬКО там. НЕ пушить, НЕ мержить, основной checkout (`/Users/peachbite/Developer/megablock10`) и `main` не трогать. Коммиты — локально, в своей ветке.

Прочти: `CLAUDE.md` (кратко: зоны, «Работа агента»), skill-подобные правила цикла ниже. Правки только через инструменты Edit/Write (не `python3 - <<EOF`, не `sed -i` по многострочному).
Читай точечно: `grep -n`, затем Read с `offset/limit`; файл > 300 строк целиком не читай; досье из карточки — не перепроверяй.

## Цикл проверки (Godot запускается ТОЛЬКО на devbox, на Mac — никогда)
- Из своей worktree: `netrun/tools/dev.sh test <имя_набора_без_.gd> [ещё_набор …]` — синхронизирует копию на devbox и гонит наборы, печатает по строке на набор.
  Имя набора — например `remote_phone_link_test`, без `.gd` и без пути.
- Полный набор (`dev.sh test --all`, 5–10 мин) — только если карточка требует, и только в фоне (Bash с `run_in_background`).
- `sleep` > 30 с запрещён хуком. Циклов без предела не делай.
- Прямой запуск gdUnit запрещён хуком — только через `dev.sh`.
- Новые `.glb/.mp3/.png` на devbox импортируются сами при прогоне тестов; файлы `*.import`, которых нет в git, rsync стирает — если карточка просит закоммитить `.import`, забери их с devbox через `scp` (путь в карточке).
- Если в логе чужая ошибка разбора скрипта (не из твоих файлов): другой исполнитель правит свою копию — это не твоё, но твоя копия на devbox отдельная, значит ошибка в твоей ветке; тогда отчёт «заблокирован».

## Коммиты
- Один коммит на шаг, зелёные тесты шага перед коммитом. Сообщение на русском: что и ПОЧЕМУ. В конец: пустая строка и `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- `git add` только своих файлов явными путями (никогда `-A` и `.`). Файлы вне зоны записи из карточки не менять. Неподходящее/странное по пути — в отчёт, не чинить.
- Не вышло за 2 попытки — откати шаг (`git checkout -- <файлы>`), назови причину в отчёте.

## Стиль
Комментарии, имена тестов и сообщения — по-русски, как в соседнем коде; GDScript типизированный (`var x: int`, `:=` там, где тип выводится). Подпись ассетов и ярких слов в UI — как в соседних файлах.

## Отчёт (≤ 15 строк, без кода)
`СТАТУС: готово | заблокирован (чем)`; коммиты (sha, тема); проверки (команда → вердикт, числа тестов); отклонения от карточки; вопросы; список изменённых файлов.
