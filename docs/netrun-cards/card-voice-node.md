## Что сделать (три коммита, тесты зелёные до каждого)

**Коммит 1 — DSP (чистые функции).** `PhoneVoiceDsp` (все `static`): `stereo_to_mono_float(frames: PackedVector2Array) -> PackedFloat32Array` (среднее L и R); `resample_linear(mono: PackedFloat32Array, from_rate: int, to_rate: int) -> PackedFloat32Array` (при равных частотах — копия); `float_to_pcm16(mono: PackedFloat32Array) -> PackedByteArray` (клип в −1…1, int16 LE); `pcm16_to_stereo(pcm: PackedByteArray) -> PackedVector2Array` (моно в оба канала); `rms_pcm16(pcm: PackedByteArray) -> float` (0…1, нормировано на 32768); `silence_pcm16(samples: int) -> PackedByteArray`.
Тест `phone_voice_dsp_test.gd`: круговое float→pcm16→stereo, клип, ресемплинг 48000→44100 длина ≈ n·44100/48000 и сохранение синуса по амплитуде, RMS тишины/полной амплитуды, нечётная длина pcm (последний байт отбрасывается).

**Коммит 2 — узел.** `PhoneVoice`: `bind(link: RemotePhoneLink)` (повторный bind отписывает прежнюю), реакции на `voice_requested`:
 - `on=true`: если разрешение микрофона не выдано (на Android — нет `RECORD_AUDIO` в `OS.get_granted_permissions()`; запросить `OS.request_permission` один раз; не-Android — считать выданным) или вход недоступен — `link.send_voice_ready(false)` и запись причины; иначе включить вход, создать `AudioStreamPlayer` с `AudioStreamGenerator` (`mix_rate = rate`, `buffer_length = 0.2`), `link.send_voice_ready(true)`, начать цикл.
 - `on=false`: выключить вход, остановить воспроизведение, очистить буферы; `voice_ready` не слать.
 Цикл в `_process`: забрать доступные входные отсчёты, привести к `rate` и моно (`PhoneVoiceDsp`), копить; по таймеру (счётчик дельт, до 5 кадров за такт) слать `link.send_voice_chunk(...)` кусками `PhoneVoiceCodec.samples_per_chunk(rate)` отсчётов: если реальных отсчётов не хватает — добить нулями (поток не должен прерываться). Дуплексное приглушение: константы вверху файла `DUCK_PEER_RMS := 0.02`, `DUCK_HOLD_MS := 150` — если звук собеседника по RMS громче порога за последние `DUCK_HOLD_MS`, отправляемый кусок = тишина; константа `HALF_DUPLEX := true` (комментарий: зачем, как выключить для замера эха).
 Приём `voice_frame_received(seq, pcm)`: отбросить seq ≤ последнего принятого (поздние/дубли; с учётом wrap uint32 — достаточно сравнения со сдвигом), потери по пропуску seq считать; в генератор класть, только если очередь воспроизведения ≤ 0.2 с (иначе отбросить кадр — задержку не копим); `pcm16_to_stereo` → `push_buffer`.
 `stats() -> Dictionary`: `{active, rate, sent, received, lost, late, overflow, ducked_ms}`; `is_active() -> bool`.
 Тест `phone_voice_test.gd`: потомок `RemotePhoneLink` с переопределёнными `send_voice_ready`/`send_voice_chunk` (записывают вызовы) и тестовый потомок `PhoneVoice` с переопределённым источником входа (метод `_pull_input(max_frames) -> PackedVector2Array` и `_input_ready() -> bool`, `_permission_ok() -> bool` — сделай их переопределяемыми): `voice_requested(true)` → `voice_ready(true)` ровно один раз и узел активен; без разрешения → `voice_ready(false)`, не активен; отключение → не активен; поток кусков идёт ровно по `samples_per_chunk` отсчётов и не прерывается при пустом входе (нули); приглушение зануляет микрофон при громком собеседнике и отпускает через `DUCK_HOLD_MS`; приём: дубли и поздний seq отбрасываются, потери считаются, переполнение очереди не растёт; повторный bind отписывает прежнюю связь.

**Коммит 3 — подключение в клиент.** В `ProtoClient._wire_remote_phone`: создать `PhoneVoice`, добавить ребёнком, `bind(remote)`; журнал: `phone.voice on=true|false rate=… ready=true|false reason=…` (по `voice_requested` и ответу узла — добавь сигнал `ready_sent(on: bool, reason: String)` в `PhoneVoice` и подпишись), и раз в 5 с пока голос активен строка `phone.voice.stat sent=… recv=… lost=… late=… overflow=… ducked_ms=…` (таймер в `ProtoClient`). Пауза очков уже закрывает связь и гасит голос (`RemotePhoneLink.pause`) — проверь это тестом клиента. Тест в `phone_client_test.gd`: при `--phone=remote` у клиента есть `PhoneVoice`, при фиктивной связи — нет; журнал содержит `phone.voice on=true` после `link.voice_requested.emit(true, 44100)` (в тесте без разрешения: `ready=false` — это допустимо) и не содержит токен.
