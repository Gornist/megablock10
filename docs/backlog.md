# Бэклог

Очередь задач по зонам (решение владельца 14.10: сессии простаивали целыми днями, пока их не позовут). Сверху — важнее.
Свободная сессия берёт верхнюю незакрытую задачу своей зоны сама: отмечает `[~]` и своё имя, делает, сдаёт PR как обычно;
после слияния строку удаляет Pipeline manager. Новую задачу пишет владелец (словами в любой сессии — она добавит строку) или
сессия, нашедшая работу вне своей зоны. Решения владельца, которые задача ждёт, — в самой строке: «ждёт: …».

Формат строки: `- [ ] [зона] что сделать — зачем / откуда` (зона — как в `scripts/zone-check.sh`).
