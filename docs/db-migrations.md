# Миграции базы данных (Room)

Текущая версия — 17 (`Mb10Database`, `version = 17`). Схема экспортируется в `app/schemas/com.megablok10.app.data.Mb10Database/<версия>.json` при каждой сборке и коммитится (в репозитории 13–17).
Версии 1–11 до релиза стираются (`DESTRUCTIVE_FROM`, `fallbackToDestructiveMigrationFrom`); с 12 и выше данные игроков не стираются никогда — только настоящие миграции, список в `ALL_MIGRATIONS`:

| Шаг | Что делает |
|---|---|
| 12→13 | таблица `outbox` (очередь исходящих) |
| 13→14 | индексы `transactions(timestamp)`, `outbox(nextAttemptAt)` |
| 14→15 | таблица `sequences` (счётчик `seq` записей для мастера переехал из SharedPreferences) |
| 15→16 | журнал подтверждённых записей `accepted_change_records` |
| 16→17 | колонка `chat_messages.status` (статус своих личных сообщений; у старых строк 0) |

## Как менять схему
1. Поменять сущность и поднять `version` в `Mb10Database`.
2. Собрать проект: Room создаст `app/schemas/.../<версия>.json`. Закоммитить его. Забытую или написанную вручную схему ловят `ExportedSchemaIdentityTest` (отпечаток `identityHash` в файле должен совпасть с тем, что пишет Room) и шаг CI «Схема Room совпадает с закоммиченной» (`main.yml`): настоящая схема печатается прямо в журнал.
3. Написать `Migration(N, N+1)` и добавить в `ALL_MIGRATIONS`. Миграция должна переживать повтор на уже мигрированной базе (`CREATE … IF NOT EXISTS`; для `ADD COLUMN` — ловить `duplicate column`, как `MIGRATION_16_17`).
4. Обновить `currentVersion` в `MigrationGuardTest`, добавить в `MigrationDataTest` случай «данные переживают шаг» (настоящая `Migration.migrate` на sqlite-jdbc, стартовая база собирается из экспортированной схемы) и пройти тесты приложения (`scripts/dbx.sh --auto`).

Страж `MigrationGuardTest` проверяет: схема текущей версии экспортирована; миграции идут подряд от 12 до текущей; версии в `DESTRUCTIVE_FROM` не пересекаются с миграциями (Room иначе падает при открытии базы).
Если пропустить шаг 3, Room упадёт при открытии базы (это намеренно): лучше найти на разработке, чем стереть кошельки на игре.
