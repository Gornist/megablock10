# Гайдлайн по стилю интерфейса «Мегаблок №10»

Как оформлять экраны приложения игрока. Правила обязательны для нового кода и для переноса экранов
([план миграции](ui-migration-plan.md)). Живой эталон всех компонентов и экранов — прототип
[prototype/mb10-ui-kit.html](prototype/mb10-ui-kit.html): откройте в браузере, вкладка «Компоненты» — каталог, «Экраны» — 19 собранных экранов.
Там же видны точные размеры и цвета. Если гайдлайн и прототип расходятся — прав прототип, гайдлайн надо поправить.

Прототип опубликован и как страница: https://claude.ai/artifact/DE1yA4qoNVSfsyUhq8PqhF (доступ — у владельца).

## 1. Принципы

1. **Как телефон из игры.** Визуальный язык взят из интерфейса телефона Cyberpunk 2077 (каталог экранов:
   https://www.gameuidatabase.com/gameData.php?id=439), но это не копия: красная «обвязка», бирюзовое «активно», зелёное «моё/успех», жёлтые деньги.
2. **Конструктор, а не рисование.** Экран собирается только из компонентов раздела 5. Своих рамок, цветов и отступов у экрана нет.
   Нужно новое — сначала вариант существующего компонента, потом новый компонент в дизайн-системе (и в каталог прототипа).
3. **Только фаски.** Никаких прямоугольных рамок и скруглённых углов — у каждой рамки срезан хотя бы один угол (раздел 4).
4. **Компактно.** Плотная подача, без «воздуха»: отступ по краю 10 dp, между блоками 8 dp. Но область нажатия — не меньше 48 dp.
5. **Читается на ходу, ночью, одной рукой.** Текст не мельче 11 sp, контраст не ниже нормы, статус никогда не держится на одном цвете.
6. **Смысл цвета не смешивается.** У каждого цвета одна роль (раздел 2). Если красный стал и рамкой, и ошибкой — это баг.

### Правила цвета

- **Красный делится на два.** `chrome` (приглушённый) — только обвязка. `bad` (яркий) — только ошибки и опасность, и всегда с иконкой.
- **Жёлтый — деньги и новое.** Предупреждение — не жёлтое, а `warn` (оранжевый) с иконкой часов.
- **Одна основная кнопка (`acc`-заливка) на экран.** Остальные — ghost или тихие.
- **Статус не держится на цвете**: у него всегда есть текст, у warn/bad — ещё и иконка (компонент StatusText).
- Не использовать прозрачность текста для «приглушения» — только токены `ink3`/`offTitle`/`offSub` (прозрачность ломает контраст).

## 3. Типографика

Два шрифта, оба под лицензией SIL OFL, **вшиваются в APK** (`res/font`, не Downloadable Fonts — на площадке нет интернета):

- **Fira Sans Condensed** 400/500/600 — весь текст, заголовки, кнопки. Узкий, как шрифт игры (сам шрифт игры Blender Pro платный).
- **IBM Plex Mono** 400/500/600 — время, статусы, служебные метки, коды взлома, адреса, суммы в списке.

| Баланс | Fira | 38 sp | 500 | цифры табличные |
| Значение плитки | Fira | 18 sp | 500 | ЗАГЛАВНЫЕ |

- **Минимум 11 sp** для всего, что несёт информацию. Мельче — только декоративные надписи (полоса «ПРОТОКОЛ 2.07» во взломе), помеченные для TalkBack как декоративные.

- Длинное название (шард) — до двух строк, потом многоточие. Превью в списке чатов — одна строка.

## 4. Формы, размеры, сетка

### Фаска — единственный способ нарисовать рамку

Три формы среза (прототип: `.fx`, `.s-tab`, `.s-dlg`):

| Форма | Срезанные углы | Где |
|---|---|---|
| **std** (по умолчанию) | правый верхний + левый нижний | кнопки, пузыри-плашки, баннер, портрет, QR, карточка |
| **tab** | правый нижний | строки-плашки, метки (Tag), «клавиши», поля, плитки, переключатель, ползунок, кнопка-иконка, таймер |
| **dlg** | правый верхний | окна (Dialog), панели взлома (Panel) |

Размер среза: 4 dp — метки и «клавиши»; 5 — «язычок»; 6 — кнопка-иконка; 7 — переключатель и ползунок; **8 — по умолчанию**;
10 — панель, QR; 12 — окно, нажатая строка; портрет — 15 % стороны.
Рамка 1 dp; у «клавиши» 1,5 dp; фокус — 2 dp белая. Пузырь сообщения — отдельная форма с хвостиком со стороны отправителя.

### Размеры

| Что | Размер |
|---|---|
| Любая нажимаемая область | **≥ 48 × 48 dp** (`Modifier.minimumInteractiveComponentSize()`; рисунок может быть меньше) |
| Строка списка | ≥ 48 dp по высоте |
| Кнопка | 48 dp высота |
| Кнопка-иконка | рисунок 40 dp, область 48 dp |
| Переключатель, ползунок | 32 dp рисунок в строке 48 dp |
| Вкладка | 46 dp |
| Нижнее меню | 52 dp |
| Ячейка матрицы взлома | 48 dp в высоту |
| Портрет | 34 (шапка), 30 (баннер), 58 (профиль), 96 (звонок) |

### Сетка

- Отступ содержимого от края экрана **10 dp**; между блоками по вертикали **8 dp**; внутри строки **8–10 dp**; между строками-плашками **4 dp**.
- Экран — колонка: шапка (не на всех экранах) → содержимое → нижнее меню. Главное действие экрана — внизу содержимого, над меню (под большим пальцем).
- Учитывать системные отступы (edge-to-edge): строку статуса рисует Android, приложение её не рисует.

## 5. Компоненты

Имя в прототипе → предлагаемое имя в Compose. Все компоненты берут цвета из темы и сами соблюдают размеры из раздела 4.

### AppShell → `MbAppShell(tab, header, content, overlay)`
Шапка: портрет-буква (тап — профиль), позывной, фракция, €$ баланс, чип «N УЗЛОВ»; под ней линия `chrome`.
Нижнее меню: 4 иконки (Чат, Звонки, Кибердека, Финансы); **у активной — подпись и бирюзовая полоса**, у остальных — жёлтый счётчик непрочитанного/пропущенного.
**Шапка скрыта** на вложенных экранах (переписка, идущий звонок, взлом) — там заголовок даёт Breadcrumb.

### Tabs → `MbTabs(items, selected)`
Иконка (необязательна) + текст, под каждым толстая полоса 3 dp; после вкладок до края тянется линия `chrome` 1 dp.
Активная — `acc` со свечением, неактивная — текст `chrome`, полоса светло-розовая `#F1C7C2`.
Одни и те же вкладки везде: «Сообщения / Звонки», «Демоны / Шарды», «Профиль / Настройки / Сеть».

### Breadcrumb → `MbBreadcrumb(parts, actions)` и MetaLine → `MbMetaLine(text, tone)`
Заголовок вложенного экрана «✉ Сообщения › Вобла» — те же отрезки, что у вкладок. **Справа — кнопки-иконки действий экрана** (позвонить, перевод).
Под ним MetaLine: строка состояния моношрифтом 11 sp («● в сети · Вольные · ключ 9C1E…04B»).

### SectionTitle → `MbSectionTitle(text, meta)`
Заголовок группы: текст `inkStrong` 13 sp, под ним линия `acc`; справа мета моношрифтом (`4`, `▽`, `поиск`). Один на всё: «Сегодня», «Контакты», «Открытые».

### ListItem → `MbListItem(lead, title, sub, trail, state, plate, mark, end)`
**Одна строка на все списки**: чаты, контакты, звонки, операции, демоны, шарды, узлы, итоги взлома.
- **lead** — иконка 18 dp, тег или портрет (необязателен); **title** — ЗАГЛАВНЫЕ 15 sp; **sub** — 12 sp; **trail** — столбец справа (время, сумма, статус, счётчик, коды, кнопка-иконка).
- Состояния: обычная; **нажата** (заливка `selFill`, рамка `acc`, форма tab 12 dp, лёгкое свечение — только пока палец на строке); прочитанная (`#9FB8B4` / `#6F8784`); не в сети (`offTitle`/`offSub`).
- Варианты: без рамки с разделителем `chromeSoft` (чаты, контакты, операции, узлы); **плашка** (рамка, демоны); **плашка с «язычком»** (журнал: шарды; нажатая краснеет `plateSel`); **текст вправо** (итоги взлома: статус-тег слева, имя и эффект справа).
- **Постоянной «выбранной» строки нет** — на телефоне нет курсора. Подсветка = нажатие.

### Tag → `MbTag(text, filled, tone)`
Моношрифт 11 sp ЗАГЛАВНЫЕ, форма tab 4 dp. Жёлтая заливка — новое и счётчики; жёлтая рамка — справочное; `warn` — нужно действие; `ok`/`bad` — итог.

### StatusText → `MbStatusText(text, tone)`
Статус моношрифтом 11 sp ЗАГЛАВНЫЕ. Тоны и словарь:

| Тон | Иконка | Тексты |
|---|---|---|
| ok | — | подтверждено, зачислено, доставлено, в сети, установлен |
| warn | часы | ждёт принятия, в очереди, нужен дешифратор |
| bad | ⚠ | не доставлено, пропущенный, не вошёл, нет связи |
| dim (`ink3`) | — | принято, отменено |

### KeyCap → `MbKeyCap(icon)` и ActionBar → `MbActionBar(actions)`
«Клавиша» из игры — иконка в рамке 22 dp. ActionBar — подвал действий экрана: линия `chrome` сверху, справа пункты «клавиша + ПОДПИСЬ» (`chrome`, 12 sp), каждый высотой 48 dp.
Не ставить ActionBar над полем ввода (клавиатура) — действия переписки идут в Breadcrumb.

### Button → `MbButton(text, kind, key, enabled)`
Форма std 8 dp, высота 48 dp, текст 13 sp ЗАГЛАВНЫЕ. Может нести «клавишу» слева.

| Вид | Заливка / рамка / текст | Когда |
|---|---|---|
| primary | `acc` / `acc` / `accInk` | главное действие экрана — одно на экран |
| ghost | `#1B1215` / `#DCCBC8` / `#F1ECEA` | второе действие рядом с главным |
| success | `#0F3A2A` / `ok` / `#DFFFEE` | подтверждение в окне: «Принять», «Подтвердить» |
| danger | `#3A1214` / `bad` / `#FFE3DF` | отказ и отмена в окне: «Отклонить», «Отмена» |
| alert | `#B3312A` / `bad` / белый | срочное необратимое: «Завершить» звонок |
| quiet | `dlgFill` / `dlgBar` / `acc` | действия под информационным окном: «Закрыть», «Передать» |

Состояния: нажата — ярче (×1,35); выключена — заливка `#1A1416`, рамка `#3A2A2C`, текст `#7D6A6D`, без свечения; фокус — белая рамка 2 dp.

### IconButton → `MbIconButton(icon, contentDescription)`
Иконка 18 dp в рамке tab 6 dp, 40 dp рисунок, 48 dp область. **Обязательна подпись для TalkBack** (e2e-стенд тоже находит кнопку по ней).

### Bubble → `MbBubble(from, text, meta)`, PayBubble → `MbPayBubble`
Входящее — слева, хвостик слева снизу, срез справа сверху; своё — справа, хвостик справа снизу, срез слева сверху. Ширина по тексту, до 82 %.
Мета моношрифтом 11 sp справа: время, «✓✓ доставлено», StatusText. Перевод — пузырь своего вида: заголовок «ПЕРЕВОД · ВОБЛЕ» (`ok`), сумма 22 sp, статус.
DaySep — «— СЕГОДНЯ —» по центру, `chrome`.

### Composer → `MbComposer`
Поле (форма tab, заливка `#140D10`, рамка `#6B3337`, 48 dp) + квадратная основная кнопка отправки 48 dp с подписью «Отправить».

### Tile → `MbTile(label, value, sub, tone, big)`
Метка `chromeDeep` моношрифтом 11 sp, значение 18 sp (крупная — 38 sp), подпись 12 sp. Тоны: money (баланс), ok (зелёная рамка — всё в порядке). Tiles — сетка 2 колонки.

### Card → `MbCard(lead, content)`, Portrait → `MbPortrait(letter, size)`, Qr → `MbQr`
Карточка с ведущим элементом (портрет или QR) и текстом. Портрет — буква в рамке `acc` с горизонтальной развёрткой.
QR — **тёмный на светлом** (`#E8F4F2`), иначе сканеры читают плохо.

### Dialog → `MbDialog(icon, title, body, actions, tone)`
Одно окно на всё: объявление мастера, чтение шарда, входящий звонок, подтверждение перевода.
- Затемнение фона 74 %. Окно: форма dlg 12 dp, заливка `dlgFill`, рамка `dlgEdge`, полоса 7 dp слева `dlgBar`.
- Заголовок: иконка `money` 18 dp + ЗАГЛАВНЫЕ 13 sp `#7FE6F2`, под ним линия. Тело: поля «**Кому:** …», абзацы, подпись моношрифтом.
- **Кнопки — под окном, справа.** Порядок как в Android: **отменяющая слева, подтверждающая справа** («Отмена | Подтвердить», «Отклонить | Принять», «Закрыть | Передать»). Не больше двух.
- tone = danger (подтверждение денег и необратимого): заливка `#3A1113`, рамка `bad`.
- Шард и объявление читаются **только в окне**, не блоком под списком.

### Banner → `MbBanner(lead, title, sub, action, tone)`
Плашка сверху содержимого — для того, что идёт сейчас: разговор (зелёная, «● В ЭФИРЕ · 01:42», кнопка alert «Завершить»); **нет связи** (tone danger, иконка «нет сигнала», «коллектор 10.10.0.10 · 3 записи ждут», кнопка «Повторить»).

### FormRow → `MbFormRow(label, control)`, Toggle, Slider, Value
Подпись `label` 13 sp слева, элемент 128 dp справа, строка 48 dp. Переключатель — две половины «ВЫКЛ | ВКЛ»: активная ВЫКЛ залита `plateSel`, активная ВКЛ — `selFill`.
Ползунок — красный бегунок на тёмной полосе, значение `acc` по центру. Value — значение только для чтения (`acc`, моношрифт 12 sp).

### EmptyState → `MbEmptyState(icon, title, text, action)` и Skeleton → `MbSkeleton(rows)`
Пустой список всегда объясняет, что сделать дальше, и даёт действие («Шардов пока нет. Отсканируйте QR-метку контейнера» + «Сканер»).
Пока грузится — строки-заглушки с мерцанием (без мерцания при «уменьшить движение»), а не пустота и не вечный спиннер.

### Взлом: Strip, Timer, Progress, Panel, Buffer, CodeMatrix, Log, Done
- Panel — рамка dlg 10 dp с залитой полосой-заголовком (`acc`, текст `accInk`, иконка чипа, справа короткая мета).
- Экран взлома **помещается без прокрутки** на 360 × 640 dp: шапки нет, ActionBar нет, «Выйти» — кнопка-иконка у таймера.
- Последовательность демона: имя слева, коды справа (уже набранные подсвечены), ниже эффект. Так же выглядит список демонов в Кибердеке.
- Успех: тема «успех», журнал `//КОРЕНЬ … //ЗАГРУЗКА_ЗАВЕРШЕНА`, полоса «Демоны загружены · 2 из 3», итоги — ListItem «текст вправо».

## 6. Шаблоны экранов

| Экран | Сборка |
|---|---|
| Список (чаты, звонки, контакты) | Tabs → (SectionTitle →) ListItem… → ActionBar или основная кнопка |
| Вложенный экран | без шапки: Breadcrumb с кнопками-иконками → MetaLine → содержимое |
| Коллекция (демоны, шарды) | Tabs → (метр ОЗУ / SectionTitle) → ListItem-плашки → основная кнопка «Сканер» |
| Деньги | Tile (баланс) → Buttons (основная + ghost) → SectionTitle по дням → ListItem операций |
| Настройки | Tabs → SectionTitle → FormRow… → ActionBar |
| Окно поверх экрана | любой экран + Dialog |

**Порядок в списках.** Сообщения: непрочитанные сверху, потом прочитанные; внутри — от новых к старым. Прочитанные приглушены.
**Операции:** слева — кто и за что, справа столбиком — сумма (знак и цвет), статус, время. Дни — SectionTitle «Сегодня», «Вчера».

### Состояния, которые есть у каждого экрана с данными
- **Пусто** — EmptyState с действием.
- **Загрузка** — Skeleton.
- **Нет связи с коллектором** (`sync.unreachable`) — Banner danger поверх содержимого; изменения копятся и уходят сами, «Повторить» — ускорить.
- **Получатель не в сети** — StatusText bad у сообщения/перевода, повтор — сам, по очереди (не дублировать отправку, см. инварианты в CLAUDE.md).

## 7. Тексты

- Весь интерфейс на русском. Пишем с точки зрения игрока: «Нет связи», а не «sync.unreachable».
- Деньги: `1 240 €$` (узкий пробел между разрядами, €$ после числа), минус — знак `−`, плюс у входящих.
- Время `23:12`; старше суток — «вчера», дальше — дата.
- Кнопка называет действие глаголом: «Принять», «Сканер», «Повторить». Статус — причастием или существительным: «доставлено», «в очереди».
- Ошибка говорит, что случилось и что будет дальше: «не доставлено — получатель не в сети» + повтор сам.
- Тексты, по которым e2e-стенд находит элементы (`scripts/e2e`: «Взломать контейнер», «Принять», «Принято», «Отправить», «Настройки»,
  «Демоны», «Шарды»), — менять только вместе со стендом в одном коммите.

## 8. Доступность

- Каждая иконка без подписи — с `contentDescription`; декоративные — `null`.
- Нажимаемое — ≥ 48 dp. Текст — ≥ 11 sp, контраст — по таблице раздела 2.
- Статус — текстом, не цветом; ошибка — ещё и иконкой.
- Фокус (TalkBack, клавиатура) виден: белая рамка 2 dp.
- Масштаб шрифта 1,3× не ломает экраны.
- «Уменьшить движение» отключает мерцание заглушек, эквалайзер звонка и вращение значка синка.

## 9. Движение и отклик

- Свечение — только на активной вкладке, активном пункте меню, нажатой строке и набранных кодах взлома. Больше свечения не добавлять (в Compose размытие дорогое).
- Анимации короткие (150–300 мс), без «въездов» содержимого.
- Вибрация: короткая — пришёл перевод, демон загружен, входящий звонок; длинная двойная — тревога СБ, взлом провален. Звук — по настройкам.

## 10. Нельзя

- Прямоугольная или скруглённая рамка (`Modifier.border` без формы, `RoundedCornerShape`).
- Цвет кодом (`Color(0xFF…)`) на экране — только токены темы.
- Текст мельче 11 sp, приглушение прозрачностью.
- Красный `bad` для украшения; `chrome` для ошибки; жёлтый для предупреждения; лайм вне взлома.
- Постоянно «выбранная» строка; больше одной основной кнопки на экране.
- Подвал действий над полем ввода; прокрутка на экране взлома.
- Свой вариант компонента «по месту» вместо варианта в дизайн-системе.

## 11. Проверка нового экрана

- [ ] Собран только из компонентов раздела 5, цвета — токены.
- [ ] Все рамки — фаски одной из трёх форм.
- [ ] Нажимаемое ≥ 48 dp, текст ≥ 11 sp, иконки подписаны.
- [ ] Есть состояния: пусто, загрузка, нет связи (если экран зависит от сети).
- [ ] Порядок кнопок в окнах: отменяющая слева.
- [ ] Выдерживает масштаб шрифта 1,3× и экран 360 × 640 dp.
- [ ] Есть скриншот-тест Paparazzi; тексты для e2e не сломаны.
