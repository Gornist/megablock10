# Дека в очках: задачи для агентов

Дизайн — [netrun-deck-design.md](netrun-deck-design.md) (все десять вопросов владельца решены 4 октября 2026). Здесь он разбит на
карточки; правила работы, общий промпт и таблица «какая модель где» — в [netrun-tasks.md](netrun-tasks.md) (не дублируются).
Принцип экономии лимитов тот же: Opus — контракты и ревью ценностей, Sonnet — код, Haiku — механика.

## Как идём быстро

- **Интеграционная ветка `agent/deck`** (от `main`, в ней дизайн и этот файл). Каждая задача — своя ветка
  `agent/deck-<id>` от `agent/deck` (`scripts/agent-worktree.sh new deck-<id> agent/deck`); готовая задача вливается в `agent/deck`
  перемоткой. В `main` — только по команде владельца, перемоткой, после CI и e2e.
- **Волны.** В волне задачи независимы по файлам и идут одновременно; следующая волна стартует, когда влиты её зависимости.
- **Одна тяжёлая задача на машину:** Gradle на devbox — по одной (сейчас только К0); gdUnit и редактор — через `flock /tmp/gdunit.lock`
  (`docs/netrun-devbox.md`). Очки одни: задачи с пометкой «очки» агент только готовит (сборка, чек-лист), играет владелец.
- **Effort.** Указан в карточке; у субагента внутри сессии он задаётся определением агента и сам не выставляется — для жёсткого
  уровня запускайте задачу отдельной сессией с нужным effort. Без явной причины Opus и `xhigh/max` не используем.
- **Проверка фактов.** Всё, что написал Haiku (команды, имена событий, форматы журнала), сверять grep'ом с кодом до вливания.

## Общий хвост для каждой карточки (дополняет общий промпт из netrun-tasks.md)

```
Дизайн: docs/netrun-deck-design.md (читай только разделы, названные в карточке), задачи: docs/netrun-deck-tasks.md.
Работай в своей рабочей копии (scripts/agent-worktree.sh new deck-<id> agent/deck). Тяжёлое — на devbox (skill devbox,
docs/netrun-devbox.md): gdUnit через flock /tmp/gdunit.lock, Gradle — не больше одного на машину. Сообщения коммитов — на русском,
«что и почему». В main и в agent/deck не вливай — только отчёт и SHA. Если карточка противоречит коду — остановись и напиши.
```
