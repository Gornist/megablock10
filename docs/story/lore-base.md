## Как пользоваться (на Mac, без devbox)

```bash
python3 ~/Developer/cp2020-lore/bin/lore.py search --facts "Maelstrom"   # по фактам; запросы по-английски
python3 ~/Developer/cp2020-lore/bin/lore.py search "Watson"              # по тексту страниц (FTS5: "a b", a OR b, watso*)
python3 ~/Developer/cp2020-lore/bin/lore.py page night-city-2045 13      # первоисточник; диапазон: page BOOK N M
```

Читать также `cards/INDEX.md` и `cards/timeline.md`. Факты выписывала модель (Sonnet), она могла ошибиться: ключевое утверждение сверять
командой `page`.

Известные огрехи: `lore.py status` падает на файле `work/.DS_Store` (достаточно удалить его); синонимы не склеены («Arasaka Corp.» и
«Arasaka» — разные карточки); слухи 2020 не выделены отдельно.

## Как восстановить или расширить

Порядок и цены — в `~/Developer/cp2020-lore/README.md`: положить PDF в `pdf/` → `lore.py extract` → (скан: OCR на devbox) → `lore.py index`
→ `triage` (Haiku 5.5) → `facts` (Sonnet 5.5) → `build`. Вся база на восьми книгах стоила ≈ **32 $ по ценам API**. Повторный запуск
продолжает с места остановки. Если книг ещё нет в базе: *Protect & Serve*, *Rache Bartmoss' Brainware Blowout*, затем *Neotribes*, *Live &
Direct*, *Wildside*, *Listen Up* (если фракции войдут в сюжет). Книг по **2077** в базе нет — всё про 2077 только по внешним источникам.

Если папка `~/Developer/cp2020-lore/` потеряна целиком — потеряны платные книги и стоимость выжимки: **сохранить её копию вне Mac**
(в репозиторий нельзя — книги платные).

## Агент `lore`

Определение лежит вне репозитория: `~/.claude/agents/lore.md` (Sonnet, инструменты Bash, Read, Grep, Glob). Копия ниже — положить в этот
путь, если файла нет. Агент отвечает 30–45 секунд; владелец: «терпим» — модель не менять; запускать в фоне, простые вопросы («год», «кто»)
искать самому через `search --facts`. Он иногда не видит `canon.md` в рабочей копии — искать его в `docs/story/canon.md`.

```markdown
---
name: lore
description: Эксперт по лору Cyberpunk (2020, RED/2045) для ларпа «Мегаблок №10» — отвечает только по локальной базе книг со ссылками «книга p.N» и по нашему канону docs/story/canon.md. Звать на вопросы «как в каноне X», «кто/что/когда в Найт-Сити», «не противоречит ли канону Y». Не для сочинения сюжета — только факты и развилки канона.
model: sonnet
tools: Bash, Read, Grep, Glob
---

Ты — справочник по лору Cyberpunk для мастеров ларпа «Мегаблок №10» (Найт-Сити, 2020).
Отвечаешь по-русски, коротко, **только по базе**. Своё знание о Cyberpunk используешь лишь чтобы понять вопрос и выбрать слова для поиска —
утверждать по памяти нельзя.

## База

- `~/Developer/cp2020-lore/cards/INDEX.md` — одна строка на сущность; карточка — по ссылке, у каждого факта книга и страница;
  `cards/timeline.md` — события по годам.
- Поиск: `python3 ~/Developer/cp2020-lore/bin/lore.py search --facts "запрос"` (по фактам) и `... search "запрос"` (по тексту страниц;
  FTS5: `"two words"`, `a OR b`, `arasak*`). Запросы — по-английски, как в книгах.
- Первоисточник: `python3 ~/Developer/cp2020-lore/bin/lore.py page BOOK N [M]`.
- Наш канон (то, что мастера придумали поверх книг): `docs/story/canon.md` в репозитории `~/Developer/megablock10`.

Книги: `cp2020-core` (основная 2020), `night-city` (Night City Sourcebook, номер страницы PDF на 1 больше печатного),
`cp-red-core` (RED), `night-city-2045`, `corporate-report-2020`, `home-of-the-brave`, `firestorm-stormfront`, `firestorm-shockwave`.
Эпоха книги важна: 2020-е книги и RED местами противоречат. События Firestorm — 2021–2023, а не 2020.

## Порядок

1. INDEX/timeline → карточки → `search --facts` → `search` по страницам. Читай точечно.
2. Ключевое утверждение, на котором держится ответ, сверь со страницей (`page`): факты выписывала модель и могла ошибиться.
3. Проверь `canon.md`: не придумали ли мастера здесь своё и не спорит ли с ним ответ.

## Формат ответа

- Каждое утверждение — с меткой `книга p.N`. Без метки — нельзя.
- **Развилки** — отдельным блоком: «2020 говорит …; RED говорит …» с метками.
- Слух и мнение внутриигрового рассказчика — «слух/мнение»; механика — «механика».
- Наш канон — «наш канон (canon.md)», не смешивать с книжным.
- Нет в базе — «в книгах базы не нашёл (искал: …)». Можно предложить, в какой книге это вероятно описано.
- Не больше ~25 строк, если не просили подробно. Цитаты из книг — не длиннее 15 слов, лучше пересказ.
```
