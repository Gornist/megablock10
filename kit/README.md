# kit — переиспользуемое ядро

Чистый Kotlin/JVM-модуль без Android и без знаний об игре «Мегаблок №10». В нём живёт то, что пригодится любому приложению
со схожей логикой: офлайн-сеть на площадке, личность игрока на ключах, подписанные передачи между игроками, мастерский сервер.

Модуль собирается и тестируется без Android SDK и эмулятора (`./gradlew :kit:test :kit:detekt`), а компилятор сам следит за
границей: код kit не может импортировать ни Android, ни классы приложения.

## Пакеты

| Пакет | Что внутри |
|---|---|
| `kit.log` | `KitLog` — журнал, в который пишут компоненты kit (приложение подставляет свой); общий формат строк событий `LogFormat`; `shortKey` — ключ в сокращении для журнала; `RotatingLogFile` — файл журнала с ротацией; `RecordingLog` и `NoopLog` для тестов. |
| `kit.time` | `Clock` — источник времени; `ManualClock` для тестов. |
| `kit.text` | `Base64Text` — свободный текст внутри построчных форматов. |
| `kit.crypto` | `Ecdsa` — ключ игрока и подписи (P-256); `Hkdf` — ключ из общего секрета; `SecretBox` — AES-GCM для содержимого QR. |

## Правила

- **Никакого Android и никакой игры.** Ни `android.*`, ни `androidx.*`, ни классов приложения. Игровые константы (префиксы
  файлов, тексты для игрока, ключи по умолчанию) передаются параметрами.
- **Только API Android 8.0 (minSdk 26).** Модуль собирается JDK 17+, но код уходит в APK: не используйте то, чего нет на
  Android 8 (`InputStream.readAllBytes`, `List.of`, `String.repeat` из Java 11 и т. п.). Стандартная библиотека Kotlin,
  `java.security`, `javax.crypto`, `java.net`, `java.util.Base64` — можно.
- **Совместимость форматов.** Всё, что уходит в сеть, в QR или на сервер, байт-в-байт совпадает с тем, что было до переезда
  в kit; такие места закреплены тестами с фиксированными векторами.
- **Журнал — через `KitLog`.** Теги и имена событий стабильны: по ним разбирают журналы живых проверок.

## Как подключить в другом приложении

```kotlin
// settings.gradle.kts
include(":kit")
project(":kit").projectDir = file("../megablock10/kit")   // или скопируйте каталог kit/ в свой проект

// app/build.gradle.kts
dependencies { implementation(project(":kit")) }
```

Модулю нужен плагин `org.jetbrains.kotlin.jvm` той же версии, что у приложения, и detekt (или уберите его из `plugins`).
