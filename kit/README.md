# kit — переиспользуемое ядро

Чистый Kotlin/JVM-модуль без Android и без знаний об игре «Мегаблок №10». В нём живёт то, что пригодится любому приложению
со схожей логикой: офлайн-сеть на площадке, личность игрока на ключах, подписанные передачи между игроками, мастерский сервер.

Модуль собирается и тестируется без Android SDK и эмулятора (`./gradlew :kit:test :kit:detekt`), а компилятор сам следит за
границей: код kit не может импортировать ни Android, ни классы приложения. Как kit встроен в Мегаблок (порты на Room, корень
композиции, сценарии поверх kit) — в [docs/architecture.md](../docs/architecture.md).

## Пакеты

| Пакет | Что внутри |
|---|---|
| `kit.log` | `KitLog` — журнал, в который пишут компоненты kit (приложение подставляет свой); общий формат строк событий `LogFormat`; `shortKey` — ключ в сокращении для журнала; `RotatingLogFile` — файл журнала с ротацией; `RecordingLog` и `NoopLog` для тестов. |
| `kit.time` | `Clock` — источник времени; `ManualClock` для тестов. |
| `kit.text` | `Base64Text` — свободный текст внутри построчных форматов. |
| `kit.crypto` | `Ecdsa` — ключ игрока и подписи (P-256); `Hkdf` — ключ из общего секрета; `SecretBox` — AES-GCM для содержимого QR. |
| `kit.net` | Строки по TCP без сервера посередине: `LineSocketClient` (одна строка на соединение, три исхода отправки `SendOutcome`), `LineServer` (приём на одном порту для нескольких протоколов через `LineRoute`, ограничение длины, таймаут, сбой соединения не роняет сервер), `WireProtocols` (версии протоколов `МАГИЯ:vN:…`) и `IncompatibleVersionReporter` (сказать игроку про телефон с другой версией). |
| `kit.handover` | Протокол передачи ценности от игрока к игроку (деньги, предметы): ценность переходит, а не копируется. `HandoverRules` — чистые правила (когда карточка считается доставленной, когда можно откатить, кому и чью карточку можно принять), `Handover` — сторона отправителя поверх порта `OutgoingJournal`: доставка без гонки с отменой и фиксация по подписанному чеку получателя. |
| `kit.sync` | Журнал изменений для мастерского сервера: `ChangeRecord` (подписанная запись «что изменилось» и формат подписи, общий с сервером), `ChangeRecorder` (подписать и положить в локальную очередь, не дожидаясь сети), `SyncEngine` (фоновый обмен: пачки, бэкофф, правки мастера и их подтверждение, heartbeat) поверх портов `ChangeQueue`, `CollectorTransport` и `SyncHooks`. |
| `kit.mesh` | Кто рядом и доставка «когда появится»: `PeerInfo`, `PeerTable` (сглаживание миганий обнаружения, отсрочка после смены сети, подсказки сервера), `Outbox` — очередь исходящих с повторами поверх порта `OutboxQueue` и графика `OutboxSchedule`. |

## Правила

- **Никакого Android и никакой игры.** Ни `android.*`, ни `androidx.*`, ни классов приложения. Игровые константы (префиксы
  файлов, тексты для игрока, ключи по умолчанию) передаются параметрами.
- **Только API Android 8.0 (minSdk 26).** Модуль собирается JDK 17+, но код уходит в APK: то, чего нет на Android 8
  (`InputStream.readAllBytes`, `List.of`, конструктор `PrintWriter(OutputStream, Boolean, Charset)` и т. п.), компилируется
  молча и падает `NoSuchMethodError` на телефоне игрока. Это проверяет Animal Sniffer по сигнатуре API Android 26
  (`./gradlew :kit:animalsnifferMain`, в CI и `scripts/check.sh`). Стандартная библиотека Kotlin, `java.security`,
  `javax.crypto`, `java.net`, `java.util.Base64` — можно.
- **Хранилища и транспорт — порты.** Где компоненту нужно хранить (очередь) или отправлять, он принимает интерфейс или
  функцию (`OutboxQueue`, `send`); реализацию на Room, SharedPreferences или OkHttp даёт приложение.
- **Совместимость форматов.** Всё, что уходит в сеть, в QR или на сервер, байт-в-байт совпадает с тем, что было до переезда
  в kit; такие места закреплены тестами с фиксированными векторами.
- **Журнал — через `KitLog`.** Теги и имена событий стабильны: по ним разбирают журналы живых проверок.

## Как подключить в другом приложении

```kotlin
// settings.gradle.kts
include(":kit")
project(":kit").projectDir = file("../megablock10/kit")   // или скопируйте каталог kit/ в свой проект

// app/build.gradle.kts
dependencies { implementation(project(":kit")) }
```

Модулю нужен плагин `org.jetbrains.kotlin.jvm` той же версии, что у приложения, и detekt (или уберите его из `plugins`).
