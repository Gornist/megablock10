# Мегаблок №10 — companion app

Приложение-спутник для кибер-панк LARP на ~100 игроков. Работает полностью
офлайн в изолированной локальной Wi-Fi сети (без интернета на площадке) —
обнаружение игроков через NSD (mDNS), весь обмен данными — прямой TCP между
устройствами, без единого центрального сервера.

## Текущий статус

Работает по-настоящему, проверено на эмуляторе и/или логически:

- **Личность игрока** — ECDSA-ключевая пара (secp256r1) генерируется один раз
  на устройстве, это и есть первичный идентификатор персонажа во всей
  системе (контакты, шарды, транзакции, чат, звонки).
- **Контакты** — обмен через QR-код (`MB10:CONTACT:v1:...`), локальный список
  в Room; в Профиле список открывается по кнопке (раскрывается, а не висит
  на экране постоянно), свой QR затемнён по умолчанию — тап показывает.
- **Чат** — фракционный и личный (DM), presence через NSD, доставка через
  прямой TCP-сокет на устройстве получателя, всё хранится в Room и переживает
  перезапуск приложения. Звук на входящее сообщение, разделители дня в
  переписке, свои/чужие сообщения визуально различаются (сторона + акцент).
- **Голосовые звонки** — сигнализация (offer/answer/ICE/decline/end) поверх
  того же TCP, что и чат; сам голос — через WebRTC (`io.github.webrtc-sdk`),
  P2P без STUN/TURN (чистый LAN). Foreground-сервис с системной
  `CallStyle`-плашкой на время звонка, гудок/рингтон/звук сообщения — три
  переданных заказчиком аудиофайла. Лог звонков (кто, направление, чем
  закончился, длительность) в Room.
- **Взлом (Кибердека / Breach Protocol)** — ревизия v9: точку доступа заменил
  **контейнер** (тир БАЗА/СЛОЖНО/КОШМАР задаёт размер сетки, таймер, мёртвые
  клетки и порченые коды; старые "AP"-QR по-прежнему читаются как контейнер
  БАЗА без лута). Демон — многоразовый инструмент (тир + эффект: извлекает
  шард/демона из контейнера, гасит или откладывает сигнал СБ, снимает
  идентификатор, добавляет время), не разовый билет с наградой на себе —
  награда (деньги + шард/демон конечного или бесконечного тиража) теперь
  на контейнере. Стартовая коллекция — один Datamine V1, дальше демоны и
  шарды добываются извлечением из контейнеров. Буфер (RAM) — свойство
  персонажа (`Identity.ramCapacity`, старт 6, потолок 13, растёт QR-токеном
  из Мастерской), не общая на всех константа. Один контейнер не платит
  лут чаще раза в 30 минут (кулдаун по его id, локально на устройстве).
  Взлом чужого контейнера уходит **сигналом СБ** фракции-владельцу — тем же
  каналом, что фракционный чат, с задержкой и содержимым по тиру контейнера
  и нейтрализаторами демона (Ghost/Timeskew/Blackout); требует активного
  Wi-Fi (иначе взлом не стартует — не обойти авиарежимом). Демоны и Шарды —
  два составных одного экрана Кибердеки с единой кнопкой "Сканировать
  объект", которая сама разбирает, что за QR перед ней.
- **Шарды** — сканируются по QR или добываются из контейнера, список с
  превью, разворачиваются в полноэкранный текст; "зашифрованные" шарды
  хранят текст скрытым, пока игрок не пройдёт отдельный мини-взлом (тот же
  движок Breach Protocol, но с одной целью — без выбора демонов, длина цели
  растёт с тиром шарда); шард может нести деньги — зачисляются один раз, в
  момент скана, как находка тайника (без подписи, без чека). Тир и
  подсказка ценности (для отыгрыша торга, без реального ценника) — тоже
  из ревизии v9; ярлык в списке ("открыт"/"зашифрован"/"фрагмент"/
  "скомпрометирован") вычисляется из тира и статуса расшифровки, не
  задаётся мастером отдельным полем.
- **Кошелёк** — перевод отправляется как обычное сообщение в личный чат с
  выбранным из контактов получателем: получатель видит платёжную карточку
  прямо в переписке и подтверждает её кнопкой "Принять", чек-подтверждение
  уходит отправителю той же переброской и фиксируется автоматически — без
  показа QR друг другу. Подпись плательщика и подпись получателя в чеке
  проверяются как и раньше, изменился только канал доставки.
- **Мастерская** — скрытый экран (доступен из Настроек) для генерации QR
  контейнеров (тир, фракция-владелец, конструктор слотов лута прямо в
  форме — шард или демон, свой тир и тираж на каждый слот), шардов (в том
  числе с деньгами внутри) и RAM-апгрейдов на месте, без отдельного
  инструмента; свой дашборд выпущенных контейнеров. Содержимое слота
  шифруется (AES-GCM, ключ в APK — от случайного скана обычным сканером
  QR мимо мини-игры взлома, не от реверс-инжиниринга) перед упаковкой в QR.
  Отдельных QR-демонов больше нет — демон выдаётся только извлечением из
  контейнера. Сама тоже на компонентах дизайн-системы.
- **Единая дизайн-система** — общий слой токенов (цвет/геометрия/типографика)
  и переиспользуемых компонентов (`ChamferedSurface`, `AppButton`,
  `AppTextField`, `StatusChip`, `AppDialog`, `AppToggle`), применённых на
  всех экранах взамен разрозненной вёрстки; живой индикатор меш-сети в
  шапке (реальное число узлов рядом, не заглушка) с дебаунсом мерцания
  `onServiceFound`/`onServiceLost` в NSD; шапка приложения и нижний
  таббар прячутся на вложенных экранах (тред чата, деталь шарда), чтобы
  не дублировать их собственный заголовок; единый стиль пустых списков;
  поиск по контактам в пикерах "новый чат"/"новый звонок".
- **Визуальный стиль** — тёмная холодная палитра (циан/коралл), лайм отдельно
  зарезервирован только за Кибердекой/шифрованием, чтобы не размывать смысл.

## Способ 1 — собрать в облаке, вообще без установки чего-либо (проще всего)

1. Залей эту папку в свой репозиторий на GitHub.
2. Открой вкладку **Actions** — сборка запустится сама при пуше в `main`,
   либо нажми **Run workflow** вручную.
3. Через пару минут в результатах прогона появится артефакт
   **megablok10-debug-apk** — скачай его, внутри `app-debug.apk`.
4. Перекинь файл на телефон любым способом (почта, Telegram себе, USB-папка)
   и установи, разрешив "установку из неизвестных источников" для того
   приложения, через которое открываешь файл.

Android Studio для этого пути не нужна вообще.

## Способ 2 — собрать локально из терминала

Нужен только JDK 17 и Android SDK **command-line tools**
(не вся Android Studio — https://developer.android.com/studio#command-tools,
это просто маленький архив с `sdkmanager`).

```bash
# один раз — поставить нужные компоненты SDK
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"

# собрать APK (используется системно установленный Gradle,
# поэтому gradle-wrapper здесь не требуется)
gradle assembleDebug

# результат:
# app/build/outputs/apk/debug/app-debug.apk
```

Установить на подключённый по USB телефон (нужен включённый USB-debugging):
```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```
Либо — как в способе 1 — просто скопировать APK на телефон и открыть.

  из ревизии v9: эксклюзивность тиража лута между устройствами (подписанные
  заявки на слот, см. `SlotClaimStore`/`ClaimProtocol`) и доставка сигнала
  СБ во фракционный чат — ни то, ни другое не проверить эмулятором, нужна
  минимум пара устройств в одной Wi-Fi сети.

Эксклюзивность тиража — не полная синхронизация реестров между
устройствами, а госсип: заявка на слот рассылается один раз, в момент
извлечения, всем сейчас видимым пирам. Устройство, которое было офлайн в
этот момент, не дозаберёт заявку задним числом — для масштаба одного акта
LARP это принятый компромисс, не забытый TODO (см. комментарий в
`ClaimProtocol.kt`).

Мастерская намеренно не получает визуальный редактор или карту площадки —
контейнеры и шарды не привязаны к физической геометрии локации, это
инструменты насыщения игровой экономики (деньги, сюжетная информация) и
тайм-киллер для игроков через майнинг данных, а не объекты на плане этажа.
